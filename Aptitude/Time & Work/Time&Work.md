TIME & WORK (Placement Notes)
1. Basic Concept

Time & Work is based on Efficiency (Work Rate).

Efficiency = Work done in one day

Golden Rules
More Efficiency → Less Time
Less Efficiency → More Time
More Workers → Less Time (if efficiency is same)
More Work → More Time (if efficiency is same)
2. Formula Triangle
            Work

      Efficiency × Time
Work = Efficiency × Time

Efficiency = Work / Time

Time = Work / Efficiency
3. LCM Method

When days are given,

Take the LCM of all days.

Assume

Total Work = LCM

Then

Efficiency = LCM ÷ Days
Why?

Instead of fractions like

1/15
1/10

we get

2 units/day

3 units/day

which makes calculations easy.

TYPE 9 : 33 UNIT WORK METHOD (Your Class Trick)

When efficiencies contain fractions like

5/2

3/2

etc.

Instead of keeping fractions,

multiply every efficiency by the same number to make them integers.

Example

A=5/2

B=3

C=2

Multiply all by

2

New efficiencies

A=5

B=6

C=4

Then take

Total Work

=

(Original LCM × 2)

This is why in class the total work changed from values like 30 to 60, or in some problems 33 units is assumed—to eliminate fractions and make calculations faster. The answer remains unchanged because both the total work and all efficiencies are scaled by the same factor.

COMMON MISTAKES

❌ Adding days.

✔ Add efficiencies.

❌ Forgetting LCM.

✔ Always find LCM first.

❌ Using old efficiency after someone leaves.

✔ Update efficiency first.

❌ Forgetting remaining work.

✔ Work Done = Efficiency × Time

❌ Treating a leak as positive.

✔ Leak = Negative efficiency.
