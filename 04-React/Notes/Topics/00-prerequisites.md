# 📚 React Prerequisites

> Before learning React, it's important to have a solid understanding of modern JavaScript (ES6+). React is a JavaScript library, so these concepts are used throughout React development.

---

# 🎯 Why Learn These Prerequisites?

React doesn't replace JavaScript—it builds on top of it.

Understanding these concepts will help you:
- Read React code with confidence.
- Understand how React works internally.
- Write clean and maintainable React applications.
- Perform better in React interviews.

---

# 📋 JavaScript Topics Required for React

| Topic | Purpose in React |
|--------|------------------|
| Variables (`let`, `const`) | Store values, state, and props |
| Arrow Functions | Event handlers, callbacks, components |
| Functions | Component logic and reusable code |
| Callback Functions | Events, array methods, asynchronous programming |
| Objects | Represent application data |
| Arrays | Store collections of data |
| Array of Objects | Render dynamic UI like product lists |
| Object Destructuring | Access props and object properties easily |
| Array Destructuring | Work with Hooks like `useState()` |
| Template Literals | Dynamic strings inside JSX |
| Ternary Operator | Conditional Rendering |
| `==` vs `===` | Comparisons and filtering |
| `map()` | Render lists of components |
| `filter()` | Search and filter data |
| Spread Operator (`...`) | Copy and update state |
| Rest Operator (`...`) | Function parameters |
| Optional Chaining (`?.`) | Safely access nested properties |
| ES Modules (`import` / `export`) | Organize React applications |

# 🏗️ How JavaScript Fits into React

```text
JavaScript
│
├── Variables
├── Functions
├── Objects
├── Arrays
├── ES6 Features
│
▼
React
│
├── Components
├── JSX
├── Props
├── State
├── Hooks
└── Context API
```

> React uses JavaScript concepts to build dynamic user interfaces.

---

# 💡 Example

### JavaScript

```javascript
const user = {
    name: "Rahul"
};

console.log(user.name);
```

### React

```jsx
function Welcome() {
    const user = {
        name: "Rahul"
    };

    return <h1>Hello, {user.name}</h1>;
}
```

React is simply using JavaScript inside JSX.

# 📌 Important Note

Learning React without understanding JavaScript is difficult.

A good React developer should first be comfortable with:
- Functions

# 🎯 Interview Questions

### 1. Can we learn React without JavaScript?

No. React is a JavaScript library, so JavaScript fundamentals are essential.

---

### 2. Which JavaScript concepts are most important for React?

- Arrow Functions
- Destructuring
- Array Methods (`map()`, `filter()`)
- Objects & Arrays
- ES Modules
- Template Literals
- Spread Operator
- Event Handling

---

### 3. Why is `map()` important in React?

Because React uses `map()` to render lists of components dynamically.

---

### 4. Why is Destructuring used in React?

It makes code cleaner and easier to read by extracting values from objects and arrays.

---

# ✅ Best Practices

- Master JavaScript before learning advanced React topics.
- Practice array methods regularly.
- Use modern ES6+ syntax.
- Understand the difference between JavaScript features and React features.
